# React ToDo Management App 🚀

A simple and practical React.js training project built to practice working with React Router, CRUD operations, reusable components, and modern UI styling.

This project provides a simple interface for creating, editing, completing, and deleting Todo tasks while practicing client-side routing and React state management.

🎯 This project was created mainly for learning and practicing React concepts and demonstrating frontend development skills.

## ✨ Features

🏠 Simple Home page with navigation links

🧭 Navigation using React Router

🔗 Active navigation states with NavLink

📝 Display Todo tasks

➕ Create new Todo tasks

✏️ Edit existing Todo tasks

🗑️ Delete Todo tasks

✅ Mark Todo tasks as completed

🔍 Filter and manage Todo tasks

🔔 Toast notifications using React Toastify

📱 Responsive UI

🎨 Styled with Tailwind CSS

## 🛠️ Technologies

React.js

React Router

Tailwind CSS

React Toastify

JavaScript

## 🏠 Home

A simple landing page containing navigation links to the different sections of the Todo application.

The Home page provides an overview of the application and allows users to navigate through the Todo sections.

## 📝 Todos

The Todo section is the main part of the application.

Users can:

Create a new Todo

Edit an existing Todo

Delete a Todo

Mark a Todo as completed

View the list of Todo tasks

Manage active and completed tasks

Receive feedback through toast notifications

## ➕ Add Todo

Users can add new Todo tasks through a simple form.

After creating a Todo, the task is added to the Todo list, and the user receives feedback through a toast notification.

## ✏️ Edit Todo

Existing Todo tasks can be filtered and updated.

The filter functionality lets users filter and view any number of tasks.

## 🗑️ Delete Todo

Users can remove Todo tasks from the list.

A toast notification is displayed to provide feedback after deleting a task.

## ✅ Completed Todos

Users can mark Todo tasks as completed.

Completed tasks are visually different from active tasks, making it easier to manage and track progress.

## 🧭 Header

The application includes a navigation header with links to:

Home

Todos

The active page is highlighted using React Router's `NavLink`.

## 🎨 UI & Styling

The application uses Tailwind CSS to create a clean and responsive user interface.

The layout is designed to work across different screen sizes while keeping the Todo management experience simple and easy to use.

## 🔔 Notifications

React Toastify is used to display feedback messages for different user actions.

Notifications are shown when users:

Create a Todo

Edit a Todo

Delete a Todo

Complete or update a Todo
